KubeGame WebSocket API (1.0.0)

Download OpenAPI specification:

License: MIT

WebSocket API specification for the KubeGame project. This API handles real-time communication between the client (frontend) and server (backend) for the Kubernetes scheduling game.

All messages are exchanged via WebSocket connection and follow a consistent structure with type, data, and timestamp fields.

client-messages

Messages sent from client to server

server-events

Events sent from server to client

heartbeat

Ping/pong heartbeat messages
